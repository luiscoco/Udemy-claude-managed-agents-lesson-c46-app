Step 0 · Prepare the application before the workflow

No API key is required for the local experiment. Optional live commentary requires your own API key, agent ID and environment ID. It explains the local result; it does not activate the integration discussed in the lesson.

For the optional live path, set your API key, then run npm run setup if you do not already have resource IDs. The script creates the environment before a text-only agent, saves each ID immediately, and reuses IDs already configured. It uses CLAUDE_MODEL or the source default; choose a model available to your account. An uncertain network failure may have created a resource: inspect your account before retrying.

/** Optional one-time provisioning. Reuses IDs already present in .env. */
import Anthropic from "@anthropic-ai/sdk";
import { existsSync, readFileSync, writeFileSync } from "node:fs";
if (!process.env.ANTHROPIC_API_KEY || process.env.ANTHROPIC_API_KEY.startsWith("your_")) {
  throw new Error("Set your own ANTHROPIC_API_KEY in .env first.");
}
const client = new Anthropic({ maxRetries: 0 });
let contents = existsSync(".env") ? readFileSync(".env", "utf8") : "";
function save(key: string, value: string) {
  const pattern = new RegExp("^\\s*" + key + "=.*$", "m");
  contents = pattern.test(contents) ? contents.replace(pattern, key + "=" + value) : contents.trimEnd() + "\n" + key + "=" + value + "\n";
  writeFileSync(".env", contents, { mode: 0o600 });
}
const valid = (value: string | undefined) => Boolean(value && !value.startsWith("your_"));
if (!valid(process.env.CLAUDE_MANAGED_ENVIRONMENT_ID)) {
  const environment = await client.beta.environments.create({
    name: "C46 student environment",
    config: { type: "cloud", networking: { type: "limited" } },
  });
  // Save immediately so a later agent failure does not lose the environment ID.
  save("CLAUDE_MANAGED_ENVIRONMENT_ID", environment.id);
}
if (!valid(process.env.CLAUDE_MANAGED_AGENT_ID)) {
  const agent = await client.beta.agents.create({
    name: "C46 text-only student agent",
    model: process.env.CLAUDE_MODEL || "claude-opus-5-5",
    system: "Answer the student's question clearly and briefly.",
    tools: [], mcp_servers: [], skills: [],
  });
  save("CLAUDE_MANAGED_AGENT_ID", agent.id);
}
console.log("Prerequisite IDs are saved in your local .env. Existing configured IDs were reused.");

4 · Optional live commentary

This separate request asks a text-only Claude session to explain the local evidence. It does not perform the lesson’s external integration.

The host creates a bounded text-only session, observes it before sending, and reports provider evidence. Read the cleanup path before interpreting failures.

export function configured() {
  return [process.env.ANTHROPIC_API_KEY, process.env.CLAUDE_MANAGED_AGENT_ID, process.env.CLAUDE_MANAGED_ENVIRONMENT_ID].every(value => value && !value.startsWith("your_"));

What the evidence proves

Executes a parameterized query on a seeded in-memory SQLite reporting database. PostgreSQL grants/RLS are not tested by this sample. Each run starts from a fresh local seed. The run journal stores results, not production workflow state.

Check the displayed outcome and source together. A rendered answer alone does not prove that a tool ran, a remote operation succeeded, or work was cancelled.
